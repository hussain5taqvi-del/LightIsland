# LightIsland Lab

Test copy of LightIsland with the experimental tools (OCR, AI quick bar, color picker, timers, translator,
reminders, QR, converters, temp mail, RAM booster, Wi-Fi / Bluetooth, snippets, crypto ticker, auto theme).
The stable LightIsland in `../LightIsland` is not touched by this folder. Lab uses its own settings folder
(`%AppData%\LightIslandLab`), its own name and its own startup entry, and it never auto-updates from the stable releases.
Do not run Lab and the stable app at the same time (both use the same hold keys).
